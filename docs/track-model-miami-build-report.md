# Miami 2026 — сборка и визуальная проверка 22.09.2026

Обновлены Blender-сцена и модель на локальной странице `/calendar/2026/4`.
Предыдущая Canvas-геометрия заменена лениво загружаемым GLB с независимым
preview при отсутствии WebGL/ошибке загрузки. Production-деплой не выполнялся.

## Исправленные замечания

- Удалены пересечения hospitality с дорожными коридорами; проверяются реальные
  треугольники сжатого GLB, включая крыши, а не только центры объектов.
- Уступ после S3 и ложный бугор после T15 возникали от максимума DTM по ширине
  дороги: в него попадала соседняя насыпь. На отметке 3767 м ошибка достигала
  7,84 м; локальный уклон — 108%. Полотно теперь следует сглаженной оси USGS.
  Согласованы рельеф и дорожный коридор, добавлена адаптивная сетка 5/10 м.
  Реальный подъём T14–T15 сохранён. На контрольном участке 3490–3550 м
  максимальный уклон профиля 3,99%, на 3720–3830 м — 0,80%.
- Съезды используют общие высоты и поперечные сечения на соединениях;
  короткие изолированные панели исключены. Верх асфальтовый, края бетонные;
  мосты не экструдируются до bare-earth DTM сплошной стеной.
- Постоянные крыши используют геопривязанные пиксели ортофото, фасады получили
  окна, рамки, двери, цоколи и карнизы. Стадион получил текстуру крыши,
  открытые ярусы и мачты по инженерному источнику.
- Трибуны стали непрерывными, с отдельными сиденьями, проходами, перилами,
  каркасом и швами навеса. Hospitality и team village получили остекление и
  террасы. Beach Club заменён открытой площадкой с двумя бассейнами и кабанами.
- Исправлено преобразование sRGB в linear для цветов GLB. Новые хеши GLB и
  preview меняют URL и исключают использование прежней версии из кеша.

## Ограничения

Временные сооружения и высоты мостов реконструированы приблизительно по
источникам, фасадные детали не являются LoD2-съёмкой. Метаданные сохраняют
`publicationStatus: review-required`: техническая проверка не заменяет
пользовательскую визуальную приёмку. Источники и методы описаны в
[карточке источников](track-model-miami-source-card.md).

`pnpm exec next build --webpack` выполнен и завершился ошибкой вне модели:
`src/components/admin/admin-schedule-list.tsx` импортирует
`src/lib/admin-job-catalog.ts`, откуда в клиентскую сборку попадает `node:crypto`
(`UnhandledSchemeError`). Поэтому успешная production-сборка и деплой
не подтверждены. Лог: `.track-model-build/miami-final-build.log`.

Для проверки по адресу пользователя временный локальный proxy на 127.0.0.1:3000
направляет запросы на уже работающий dev-сервер 3107; конфигурация проекта
и production-настройки не менялись.
